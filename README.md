# 🤖 Line Follower Robot

## Overview
This project is a ROS 2 Jazzy based Line Follower Robot developed using Python. The robot follows a predefined line autonomously using line detection logic.

## Features
- Autonomous line following
- ROS 2 Jazzy
- Python implementation
- Modular package structure

## Technologies Used
- ROS 2 Jazzy
- Ubuntu 24.04
- Python
